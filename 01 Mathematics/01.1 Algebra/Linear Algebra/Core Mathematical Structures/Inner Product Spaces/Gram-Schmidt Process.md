> [!abstract] Definition
> The **Gram-Schmidt process** is an algorithm that transforms a linearly independent set of vectors into an orthogonal or orthonormal set spanning the same subspace.
>
> It constructs orthonormal bases while preserving the subspace generated by the original vectors.

## 1. Mathematical Objective

> [!important] Input and Output
> Given linearly independent vectors:
>
> $$\{v_1,v_2,\ldots,v_k\}$$
>
> The Gram-Schmidt process constructs orthogonal vectors:
>
> $$\{u_1,u_2,\ldots,u_k\}$$
>
> satisfying:
>
> $$\operatorname{span}\{u_1,\ldots,u_k\}
> =
> \operatorname{span}\{v_1,\ldots,v_k\}$$
>
> Normalizing the resulting vectors produces an orthonormal basis.

## 2. Orthogonalization Algorithm

> [!important] Step 1 — First Vector
> Set:
>
> $$u_1=v_1$$

> [!important] Step 2 — Remove Existing Components
> For each subsequent vector $v_j$, subtract its projections onto all previously constructed orthogonal vectors:
>
> $$u_j=v_j-\sum_{i=1}^{j-1}
> \frac{\langle v_j,u_i\rangle}
> {\langle u_i,u_i\rangle}u_i$$
>
> The resulting vector is orthogonal to all preceding vectors.

> [!important] Step 3 — Normalize
> Construct unit vectors:
>
> $$q_j=\frac{u_j}{\|u_j\|}$$
>
> The resulting set $\{q_1,\ldots,q_k\}$ is orthonormal.

## 3. Geometric Interpretation

> [!note] Removing Existing Components
> At each iteration, the algorithm removes the components of the current vector that lie along the previously constructed orthogonal directions.
>
> What remains is the component perpendicular to all those directions.
>
> This process is repeated until an orthogonal basis for the original subspace is obtained.

## 4. Important Properties

> [!important] Preservation of Span
> At every iteration:
>
> $$\operatorname{span}(u_1,\ldots,u_j)
> =
> \operatorname{span}(v_1,\ldots,v_j)$$
>
> Therefore, the final orthogonal set spans exactly the same subspace as the original set.

> [!important] Orthogonality
> The constructed vectors satisfy:
>
> $$\langle u_i,u_j\rangle=0
> \quad\text{for }i\neq j$$

> [!important] Orthonormality
> After normalization:
>
> $$\langle q_i,q_j\rangle=\delta_{ij}$$

> [!warning] Linear Independence Requirement
> The standard Gram-Schmidt process assumes that the input vectors are linearly independent.
>
> If a generated vector $u_j=0$, the original vector is dependent on the preceding vectors, and normalization is impossible.

## 5. Matrix Interpretation

> [!definition] QR Factorization Connection
> Let $A\in\mathbb{R}^{m\times n}$ have linearly independent columns.
>
> Applying Gram-Schmidt to its columns produces:
>
> $$A=QR$$
>
> where:
> - $Q\in\mathbb{R}^{m\times n}$ has orthonormal columns.
> - $R\in\mathbb{R}^{n\times n}$ is upper triangular.
>
> This is the reduced QR factorization.

> [!note] Numerical Stability
> The classical Gram-Schmidt algorithm can lose orthogonality due to floating-point rounding errors.
>
> Modified Gram-Schmidt generally improves numerical stability, although Householder QR is often preferred for robust numerical computations.

## 6. Knowledge Relationships

### Foundation Knowledge
- **Linear Independence** — ensures each new vector contributes a new independent direction.
- **Inner Products** — define the projection coefficients.
- **Orthogonality** — defines the required relationship between constructed vectors.
- **Orthonormal Bases** — provide the target structure.

### Downstream Knowledge
- **QR Factorization** — expresses a matrix using the orthonormal vectors generated by Gram-Schmidt.
- **Least Squares** — uses orthogonal factorization to solve approximation problems.
- **Numerical Linear Algebra** — studies stability and computational alternatives to classical Gram-Schmidt.
