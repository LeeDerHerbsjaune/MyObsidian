### 5.3. Coordinate systems versus reference frames

> [!important] Conceptual distinction
>
> A coordinate system defines how spatial quantities are numerically represented.
>
> A reference frame identifies the particular origin and orientation used as the reference for those quantities.
>
> A transformation between reference frames changes the coordinate representation of the same geometric quantity.
>
> This distinction is important because changing coordinates does not necessarily mean that the physical object has moved.
